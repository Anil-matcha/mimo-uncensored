# Glossary

## Abliteration

A family of model-editing methods used to reduce some refusal behavior. The term does not imply that a model has no safeguards or guarantee a particular response.

## Context window

The total token budget a model can process for an input and generated continuation. The context figure in Muapi's catalog is separate from max_tokens, which limits output.

## Derestricted

A route label used by Muapi for some variants. It does not certify a refusal rate or change Muapi's acceptable-use policy.

## Endpoint ID

The path name after the Muapi API base URL, such as mimo-v2-6-flash-abliterated.

## Input and output tokens

Input tokens are the prompt and supported context sent to the model. Output tokens are generated by the model. Muapi may publish separate rates for each.

## Obliterated

A route or variant label used in some model names. Treat it as catalog nomenclature, not a measured property.

## Request ID

The identifier returned when Muapi accepts an asynchronous request. Use it to poll for the result.

## Server-Sent Events (SSE)

A streaming response format that sends data events as output becomes available. Use it only on routes for which Muapi documents streaming.

## System prompt

Optional instructions sent separately from the user prompt to guide response style or task framing.

## Token

A unit used by language models to represent text. Token counts do not map one-to-one to words.
